# Atril institucional ADN · Colegio de Biólogos del Perú

## Concepto corregido por el cliente

El atril queda reducido a los elementos estrictamente solicitados: **dos elementos verticales inspirados en el ADN**, una **doble hélice ubicada en la base** y, por encima, un **único apoyo inclinado para libros o cuadernos**. Se eliminan panel frontal, madera decorativa, vidrio ornamental, micrófono, lámpara, iluminación LED, logotipos, cables visibles y cualquier accesorio adicional.

## Características propuestas

| Elemento | Propuesta preliminar |

| Uso | Conferencias, ceremonias, congresos, defensa de ponencias y actos institucionales |
| Altura total | 1,15–1,20 m referencial |

| Profundidad | 0,55–0,65 m referencial |

| Equipamiento | Únicamente apoyo inclinado para libros o cuadernos |

| Base | Zócalo amplio anti-vuelco, con niveladores y protección de piso |
| Identidad | Motivo de doble hélice integrado en la estructura, sin depender de un logotipo pintado |

## Criterios de diseño

El atril debe ser reconocible desde el auditorio sin competir visualmente con el expositor. La superficie de apoyo se mantiene despejada y la geometría debe comunicar con claridad la secuencia: **doble hélice inferior → dos elementos de ADN → apoyo superior**. La base debe resistir uso intensivo, transporte ocasional y limpieza institucional.

La solución puede fabricarse en dos versiones: una versión principal para el auditorio mayor y una versión ligera para los cuatro auditorios secundarios. Ambas deben conservar exactamente la configuración de dos elementos de ADN, doble hélice inferior y apoyo superior.

## Seguridad y ergonomía pendiente

Antes de fabricar se deben validar dimensiones con usuarios reales, estabilidad frente a empujes, radios de borde, resistencia de materiales, accesibilidad, altura del apoyo y facilidad de colocar o retirar libros y cuadernos. La presente ficha es conceptual y no reemplaza planos de fabricación ni cálculo estructural del mueble.

## Acabado recomendado

Base, doble hélice y elementos verticales en acero inoxidable satinado o metal de acabado claro. El apoyo superior puede ser una placa metálica lisa, ligeramente inclinada, con un pequeño borde retenedor para evitar que los libros o cuadernos se deslicen.
