# Snapshot completo de la UI standalone

La página independiente `arki-ui-reference.html` fue abierta sin autenticación ni conexión con ARKI/Core. Se verificó visualmente el layout de tres columnas y se probó el botón **Planta**, que cambió el visor y mostró el aviso “Vista Planta seleccionada”.

La página contiene familias paramétricas, variantes, sliders de niveles y área, vistas 3D/Planta/Corte/Elevación, controles Path Tracing y WebXR con estado GATED, calidad, resolución, exportación, comparación y guardado de snapshot.
