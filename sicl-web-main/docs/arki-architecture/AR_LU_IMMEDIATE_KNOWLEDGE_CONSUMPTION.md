# AR-LU — consumo inmediato de conocimiento aprobado

A partir de la versión `AR-LU-KNOWLEDGE-EXCHANGE-2.0`, una aprobación válida en ARKI o LUCA habilita el consumo del registro compatible en ambos productos, sin volver a cargar el mismo libro. Los dominios compartidos incluyen GIS, georreferenciación, arquitectura, paisajismo, turismo, guías turísticas, guías de viaje, guías para viajeros, patrimonio, visión y dispositivos.

La notificación incluye el commit y archivo de origen. El runtime puede consumir inmediatamente el registro aprobado como conocimiento revisado, pero esto no significa que el contenido sea universalmente verdadero ni que se haya leído un libro completo. La provenance y el estado Delta 6.2 permanecen visibles.

Los registros `STAGED` siguen pendientes. Un desacuerdo no borra el conocimiento: lo pone en cuarentena y solicita revisión. La política de auditoría queda bajo demanda: no se audita repetidamente durante el trabajo normal; se valida cuando haya push urgente, cambio de alto riesgo o una necesidad explícita de seguridad. Las pruebas focalizadas continúan siendo obligatorias antes de entregar cambios funcionales, pero no se ejecutan auditorías amplias innecesarias.
