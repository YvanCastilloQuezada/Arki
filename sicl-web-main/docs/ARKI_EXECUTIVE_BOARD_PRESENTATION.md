# Guion ejecutivo para junta directiva

El guion ejecutivo oficial se mantiene en el repositorio Core para evitar divergencia entre arquitectura, handover y presentación:

[SICL Core executive presentation](https://github.com/YvanCastilloQuezada/sicl-core/tree/main/docs)

## Uso

Utilice este guion junto con:

- `ARKI_FIRST_CONTACT_MANUAL.md` para la demostración inicial.
- `ARKI_FRONTEND_HANDOFF.md` para explicar el estado del frontend.
- `ARKI_PROJECT_HANDOFF_2026-09-16.docx` para revisar arquitectura, pruebas, seguridad y pendientes.

La presentación debe conservar una afirmación esencial: ARKI puede analizar y proponer, pero la autoridad de decisión permanece humana.
