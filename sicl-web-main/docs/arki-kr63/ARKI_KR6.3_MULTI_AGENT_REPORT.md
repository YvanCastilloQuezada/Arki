# ARKI KR-6.3 Multi-Agent Consolidation

**Status:** `CONSOLIDATED / IMPLEMENTED_WITH_BOUNDS / HUMAN_AUTHORITY_FINAL`

This workbook preserves KR-6.2 as the baseline and adds a multi-agent registry, six target families, orchestration contracts, recent capability statuses and explicit limits. Existing agents AGENT-BRIEF, AGENT-PARTI, AGENT-REGULATION and AGENT-COST are retained. The five Superpowers specialists are registered as implemented and tested. Red Team, Contradiction Hunter and Cross-project Transfer remain partial/bounded. The A00–A59 target catalog is recorded without invented names because the supplied order references the range but does not enumerate it.

The workbook does not claim multi-agent intelligence demonstrated merely because a registry exists. No agent can approve a project, promote UNKNOWN to FACT, overwrite a human decision or replace specialist responsibility.
