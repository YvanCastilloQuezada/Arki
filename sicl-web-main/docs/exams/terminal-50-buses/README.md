# Terminal interprovincial para 50 vehículos

## Entrega conceptual

ARKI procesó un encargo de terminal terrestre interprovincial para 50 buses. La propuesta contiene programa funcional, separación de flujos, esquema de sitio y planos conceptuales de N1 y N2.

## Supuestos explícitos

- Terreno conceptual: 120 x 180 m.
- Un frente público en el borde sur.
- Cincuenta dársenas de buses organizadas en cinco filas de diez.
- Edificio terminal de dos niveles.
- Banda posterior independiente para carga, servicio, equipaje, mantenimiento y residuos.
- La propuesta no está ajustada todavía a un terreno real, jurisdicción concreta o expediente normativo.
