## Límites

El modelo está clasificado como `CONCEPTUAL_FLOOR_PLAN` y sus espacios permanecen en estado `HYPOTHESIS`. No declara cumplimiento normativo, documentación constructiva, permiso, dimensiones definitivas de ingeniería, cálculo de evacuación ni conformidad de rutas accesibles. Los shafts son reservas conceptuales con dimensiones `UNKNOWN`.
