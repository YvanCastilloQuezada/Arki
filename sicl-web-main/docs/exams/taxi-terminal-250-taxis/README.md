# Terminal de taxis para 250 vehículos — tres propuestas

## Encargo procesado

ARKI generó tres alternativas conceptuales para un terminal de taxis con capacidad de 250 vehículos en un terreno de 20,000 m².

## Supuestos explícitos

- Terreno conceptual rectangular de 100 x 200 m.
- Un frente público principal en el borde sur.
- Las 250 posiciones son de holding/regulación; el dimensionamiento final depende de rotación y demanda.
- Separación de pasajeros, taxis operativos, personal, mantenimiento, carga, EV/combustible y residuos.
- Propuesta A: organización lineal.
- Propuesta B: plaza central con cuatro islas.
- Propuesta C: terminal compacto con operación en dos niveles y holding periférico.
