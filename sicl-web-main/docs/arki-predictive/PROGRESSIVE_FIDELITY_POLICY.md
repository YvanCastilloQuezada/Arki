# Progressive Fidelity Policy

La inversión computacional crece cuando se reduce el número de candidatos: N recibe evaluación barata; 16 recibe elegibilidad y exploración visual; 4 recibe análisis comparativo más profundo; 1 entra a desarrollo gobernado.

No se simula una evaluación profunda ausente. Un solver no disponible produce `BLOCKED`, `PARTIAL` o `UNKNOWN`, con causa explícita. El autopilot puede continuar tareas autorizadas entre etapas, pero se detiene ante una decisión arquitectónica humana.
