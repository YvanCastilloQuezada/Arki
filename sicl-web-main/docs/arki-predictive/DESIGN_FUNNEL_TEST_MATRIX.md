# Design Funnel Test Matrix

La suite cubre: 16 iniciales; selección distinta de cuatro; duplicados; menos de cuatro; selección cruzada entre proyectos; promoción obsoleta; bloqueo durante evaluación; intento de seleccionar antes del análisis profundo; selección humana 4→1; preservación de 12 y 3; retorno reversible; y rechazo de modos de comparación no implementados.

Los mutantes conceptuales protegidos son `AUTO_WINNER`, `DELETE_REJECTED`, `FIFTH_FINALIST`, `CROSS_PROJECT_SELECTION`, `STALE_FINALIST_PROMOTION`, `SELECTION_WITHOUT_EVIDENCE` y `FALSE_FINAL_VALIDATION`.
