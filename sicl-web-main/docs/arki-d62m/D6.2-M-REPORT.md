## Bridge implemented

The bridge represents the following executable chain:

```text
PROJECT_INPUT
→ RETRIEVED_KNOWLEDGE
→ REQUIREMENTS
→ UNKNOWN
→ DEFICITS
→ CAUSE_HYPOTHESES
→ STRATEGIES
→ REALIZATIONS
→ TOPOLOGICAL_RELATIONSHIPS
→ CANDIDATE_TOPOLOGY
```

The implementation explicitly preserves the distinctions between activities, allocation requirements, strategies, realizations, topology, and geometry. It does not create rooms, walls, doors, dimensions, coordinates, zoning, BIM, or floor plans.
