# ARKI product visual index — A0.R3

This package is a forensic closure of A0.R2. It is read-only and does not repair the application.

The package contains an exact 38-entry route accounting, a screen registry, causal clusters, App.tsx diagnostic, independent TypeScript/build/test/runtime baselines, control normalization, a screen review matrix, a visual issues register, non-binding disposition proposals, an executive product map and a complete contact sheet of the 110 preserved 4001 captures.

The raw screenshot corpus is preserved byte-for-byte under `screens/`. Because the browser tool names screenshots by timestamp rather than route, the registry explicitly records route-association uncertainty instead of inventing a one-to-one mapping.
