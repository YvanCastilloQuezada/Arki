# SICL Frontend Specification v1.0 — Clasificación

**Clasificación:** RFC UX/UI para SICL 0.7+

**Estado:** No autorizada para implementación en SICL 0.6.

**Regla de alcance:** Este documento es únicamente una referencia futura de experiencia de usuario. No autoriza modificaciones a componentes React, estilos, rutas, textos, copilotos, modos de inmersión, mapas, visualizaciones 3D, voz ni nuevas capacidades del Core Contract durante SICL 0.6.

**Autoridad:** Product Owner.

**Relación con el release 0.6:** SICL 0.6 mantiene el frontend y el contrato actuales. Cualquier incorporación futura deberá pasar por RFC, delimitación de alcance, contrato, pruebas, evidencia y aprobación independiente.

**Fuente archivada:** `docs/SICL_FRONTEND_SPEC_v1.md`.
